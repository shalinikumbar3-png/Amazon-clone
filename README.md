# Amazon Homepage Clone

A front-end web development project replicating the layout and visual design of the Amazon e-commerce homepage using semantic HTML5 and custom CSS3[span_0](start_span)[span_0](end_span).

## Features

* **Navigation Header & Sub-Panel:** Includes the main navigation bar with the Amazon logo and quick-access links (`Today's Deals`, `Customer Service`, `Registry`, `Gift Cards`, `Sell`)[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span).
* **Hero Banner Section:** Full-width promotional hero banner with a localized shopping message overlay[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).
* **Product Category Grid:** Multi-column layout displaying various shopping categories (such as *Health & Personal Care*) with custom product imagery[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
